# Changelog

## 0.1.0 — 2026-09-21

- Manual/daily bounded YouTube channel and Instagram Reels collection using existing HTTP Request nodes.
- Shared starter normalization, platform-qualified IDs, source links, nullable metrics and explicit partial failures.
- PostgreSQL destination leases, durable pending digests, post-confirmation deduplication and restart-safe state.
- Slack digest without mandatory AI, with documented at-least-once retry semantics and capped requests.
